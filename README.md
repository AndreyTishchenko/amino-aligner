# Amino Aligner

Web application for visualizing and comparing amino acid sequences.

The project allows users to input protein sequences and view aligned amino acids with colorized visualization for easier biological analysis.

## Features

- Amino acid sequence input
- Sequence alignment visualization
- Color-coded amino acids
- Interactive UI
- Responsive layout

## Tech Stack

- React
- TypeScript
- Vite
- CSS

## Installation

```bash
npm install
```

## Run Project

```bash
npm run dev
```

## Purpose

The application is designed for simple visualization and comparison of amino acid sequences in a user-friendly interface.
